## Goal

Alinear toda la capa de código TypeScript con el schema introducido en Phase 15 (tabla `groups`, FK `trees.group_id`, columna `parcela_id`, firma de `generateSubId` con 4 argumentos). Renombrar `SubGroup`→`Group` y `subgrupo`→`grupo` en **identificadores de código** (tipos, variables, props, nombres de función, parámetros, importaciones de tabla, archivos), y renombrar los archivos cuyo nombre refleja la entidad. Tras este plan, `npx tsc --noEmit` debe quedar en **0 errores** y `npm test` (unit + integración existente) debe quedar verde. Textos visibles en JSX (labels, títulos, mensajes) quedan **fuera de scope** — Phase 17.

## Risks & Mitigations

1. **Riesgo:** Renombrar un identifier que en realidad es un nombre de columna SQL raw embebido en `sql\`...\``. **Mitigación:** Task 1.1 categoriza explícitamente cada match; los strings dentro de template literals se revisan caso por caso. Verificar con `grep "sql\`" mobile/src` después del rename.
2. **Riesgo:** Perder reactividad (useEffect dep arrays, useLiveData deps) durante el rename. **Mitigación:** Task 1.8 incluye diff old-vs-new audit explícito (memory `feedback_refactor_audit.md`).
3. **Riesgo:** Los call-sites de `generateSubId` pasan `''` como `parcelaCodigo` placeholder (Task 1.4), lo que generaría SubIDs corruptos en runtime si Phase 17 no se completa. **Mitigación:** El placeholder genera SubIDs visiblemente rotos (sin prefijo de parcela) — esto es DELIBERADO y detectable en QA. Documentar como deuda en el commit y en `tasks/16-01-deuda-phase17.md`.
4. **Riesgo:** Server tabla `subgroups` aún existe en Supabase (si P15 server-side migration no se aplicó). **Mitigación:** Pre-condition explícita verifica `supabase/migrations/012_*.sql` aplicada. Si no, Task 1.5 falla y se devuelve a Phase 15.
5. **Riesgo:** Tests pasan localmente pero CI rompe por archivo no renombrado en git (case-sensitivity en Linux vs. macOS). **Mitigación:** Usar `git mv` (no rm+add) en cada rename; verificar con `git status` que aparecen como `R` (rename).
